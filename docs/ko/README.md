# Decision 한국어 문서 모음

이 문서는 **이론 이해 → 코드 구조 이해 → 판별 조건 작성 → 실습과 검증** 순서로 읽도록 구성했습니다. 처음에는 아래 그림과 이론 설명서를 보고, 직접 조건을 넣을 때는 작성 안내서의 예제를 따라가세요.

![생성 의도와 관측 결과를 분리하는 전체 흐름](../assets/pipeline-overview.svg)

## 읽는 순서

| 순서 | 문서 | 이 문서를 읽고 할 수 있는 일 |
|---|---|---|
| 1 | [이론 설명서](THEORY.md) | Decision 모델과 규칙의 차이, 확률·보류·시간 정보·평가의 의미를 설명합니다. |
| 2 | [기술 구조 설명서](TECHNICAL_DESIGN.md) | 입력이 어떤 함수와 모델을 거쳐 보고서로 바뀌는지 코드와 연결해서 읽습니다. |
| 3 | [판별 조건 작성 안내](CRITERIA_AUTHORING.md) | 질문·목표·임계값을 구분하고, 새로운 조건을 추가해서 시험합니다. |
| 4 | [기존 판별 조건과 반례](SEMANTIC_CRITERIA.md) | 기본 여덟 항목의 판정 근거와 실수하기 쉬운 사례를 확인합니다. |
| 5 | [설치와 실제 모델 연결](SEMANTIC_VIDEO_GUIDE.md) | 로컬 Valen이나 Cosmos 서버에 실제 영상을 연결합니다. |
| 6 | [실습 노트북](../../notebooks/S1_Semantic_Video_Verification.ipynb) | CPU 예제로 전체 흐름을 실행한 뒤 실제 모델 실습으로 확장합니다. |
| 7 | [검증 기록](SEMANTIC_VALIDATION.md) | 확인한 범위와 아직 측정하지 않은 성능을 구분합니다. |
| 8 | [GitHub 게시 안내](GITHUB_GUIDE.md) | 소스·문서·노트북을 저장소로 관리합니다. |

모델을 바꿔 비교하려면 [모델 설정과 교체](MODEL_CONFIGURATION.md)를 이어서 읽으세요. 모델 설정 JSON, 판별 기준 JSON, 영상별 목표가 각각 어디에 들어가는지와 새 연결 클래스의 계약을 설명합니다.

GPU로 실제 추론을 시작할 때는 [GPU 실행 안내](GPU_GUIDE.md)를 보세요. CUDA 환경 설치, 노트북 커널, `device` 설정, 여러 GPU 중 하나 선택하기, 메모리 부족 대응, 원격 서버 방식의 차이를 설명합니다.

실제 자료를 정리할 때는 [확신도별 분류와 보고서](CONFIDENCE_CLASSIFICATION.md)를 보세요. 확신도 → 상황 순서로 원본을 복사하고 HTML·MD·CSV·JSON 결과를 만듭니다. 여러 GPU의 자동 작업 배정과 모델 병렬화의 차이는 [GPU 자동 분산](GPU_DISTRIBUTION.md)에 정리했습니다.

## 그림과 조작형 시각화

- 문서의 SVG 그림은 GitHub에서 바로 볼 수 있습니다.
- Mermaid 도식은 GitHub에서 렌더링됩니다. 지원하지 않는 편집기에서도 바로 아래 설명과 표로 같은 내용을 읽을 수 있습니다.
- [임계값에 따른 분기 실험](../assets/decision-explorer.html)은 저장소를 내려받은 뒤 브라우저에서 열면 됩니다. 인접한 `decision-explorer.js` 파일도 함께 있어야 합니다. GitHub 파일 미리보기에서는 HTML이 실행되지 않습니다.

분기 실험은 여섯 개 **가상 관측값**에 대해 확률·선택지 차이·시간 공백 기준을 바꾸는 도구입니다. 실제 영상이나 모델 서버를 호출하지 않습니다. 조건을 느슨하게 하면 자료가 더 통과할 수 있지만, 새로운 관측 근거가 생기는 것은 아니라는 점을 살펴보세요.

## 바로 실행할 수 있는 조건 추가 예제

저장소 루트에서 기본 패키지를 설치한 뒤 실행합니다.

```bash
python -m pip install -e .
python examples/custom_criteria_demo.py --out .study-runs/road-wet-001
```

이 예제는 “도로가 젖어 보이는가?”라는 `road_wet` 질문을 추가합니다. 결과는 후보·재분류 후보·보류가 각각 한 개입니다. 자세한 설명은 [판별 조건 작성 안내](CRITERIA_AUTHORING.md)에 있습니다.

## 스터디 운영 제안

| 진행 | 읽을 내용 | 실습·토론 |
|---|---|---|
| 첫 30분 | 이론 설명서의 목표·관측·규칙 | 왜 젖은 도로와 현재 비가 오는 장면을 나눠야 할까요? |
| 다음 30분 | 기술 구조와 시간축 | 2Hz를 10fps로 저장한 영상에 실제로 늘어난 정보가 있나요? |
| 다음 40분 | 조건 작성 안내와 예제 | 새로운 질문 하나를 만들고 양성·음성·판단 불가 예를 적습니다. |
| 마지막 20분 | 분기 실험과 평가 | 통과율이 높아진 것이 정확도 개선인지 기준 완화인지 구분합니다. |

기본 자료는 영상의 **시각적 의미 재분류**를 다룹니다. 음성 인식, 실제 차량 제어, 모델 학습, 충돌 위험의 계측은 별도 구성 요소가 필요합니다.
